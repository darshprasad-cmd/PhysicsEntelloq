Learning tools: sources and boundaries

These capabilities live inside the existing Physics workspace. Each tool loads when selected and retains its own clearly named local storage.

  • MathLive provides structured notation input. An equation being well-formed does not prove it correct.
  • JSXGraph renders linked vector and graph controls. Numerical controls provide an alternative to dragging.
  • CircuitJS1 is a separate GPL circuit simulator loaded from its official online host after you launch it. Its model assumptions do not establish real-world electrical safety.
  • ts-fsrs schedules review from explicit retrieval ratings. It is separate from assessment scores and does not certify mastery.
  • Yjs preserves concurrent notebook edits. The notebook describes the supported sharing mode; it does not imply a hosted classroom account service.
  • Transformers.js runs optional semantic lesson search. A model downloads only when enabled. Downloads, memory use and device support affect availability; lexical search remains available.

Your saved work

Review history, graph settings and notes stay in this browser origin. Use the tools' exports to keep copies. A different browser, origin or local file does not automatically inherit those records.
