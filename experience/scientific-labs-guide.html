What runs here

Reality Lab

OpenCV tracks a selected patch in a local video. You calibrate length and origin, then compare measured positions with browser physics models. Perspective, occlusion and calibration errors affect the result; synthetic test footage does not establish real-camera accuracy.

Reality source guide ↓

Discovery Notebook

marimo runs reactive Python in your browser. Pendulum and projectile fits report model-dependent uncertainty; sampling explores aliasing. Generated datasets are labelled synthetic, and you can import your own CSV.

Discovery source guide ↓

Symbolic Workbench

SymPy computes through browser Python. Domains and assumptions remain part of the answer. An expression comparison on a shared domain does not verify a whole mathematical argument.

Symbolic source guide ↓

Robotics Workbench

Geometry and a labelled recorded Genesis run are available in the browser. New dynamics require a local Genesis service. The model is one horizontal two-link arm; it is not a hardware validation or a learned policy.

Robotics setup & source ↓

Proof Studio

Build a draft from guided choices and inspect the generated Lean source. A result is verified only after the local Lean checker accepts that exact formal statement and argument. An offline draft stays unverified.

Run the native engines locally

Browser tools work on the hosted site. For new Genesis runs and Lean checks, use a local copy of this Physics repository and follow each engine’s setup guide above to install its pinned requirements.

From the Physics project folder, start the local workspace:

python scientific-labs/serve-physics.py

Then open Physics on this computer. In separate terminals, using the Python environment where each engine is installed:

python scientific-labs/robotics/server.py --port 8772
python scientific-labs/proof/server/app.py --port 8773

The companion serves this complete Physics application locally and connects its tools to those services. It does not install or start either engine automatically. Closing a service makes its new computations unavailable.

Data, source and attribution

Video selection and notebook CSV analysis stay in your browser. Browser Python downloads its runtime on first use, which requires an internet connection and may take several minutes. Download results you want to keep before leaving a tool; unsaved work resets when its embedded document closes.

Editable implementations, dependency versions, scientific tests, licences and provenance are kept in the repository under scientific-labs/reality, reason, discovery, robotics and proof. The existing Physics shell integration is authored in experience/scientific-labs.js.
